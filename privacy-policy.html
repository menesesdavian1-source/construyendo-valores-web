Política de privacidad

Construyendo Valores Studio · Última actualización: 12 de noviembre de 2026

1. Resumen

Construyendo Valores Studio es una aplicación de escritorio de un solo usuario. La usa únicamente el creador del canal de YouTube Construyendo Valores para producir videos infantiles educativos originales y publicarlos en su propio canal. La aplicación no está disponible para otros usuarios, no contiene anuncios y no vende ni comparte datos.

2. Uso de los servicios de la API de YouTube

Esta aplicación utiliza la YouTube Data API v3 de Google. Al usarla, el usuario acepta las Condiciones del Servicio de los Servicios de la API de YouTube y la Política de privacidad de Google.

La funcionalidad de la aplicación que usa la API de YouTube es: subir videos al canal autorizado, programar su publicación, elegir su privacidad (público, privado u oculto) y consultar el estado de los videos del canal.

3. Qué información accedemos, guardamos y usamos

La aplicación solo accede a los datos del propio usuario (el dueño del canal) a través de OAuth 2.0:

  • Nombre e identificador del canal autorizado.
  • Lista de videos del canal y su estado de privacidad.
  • Metadatos (título, descripción, etiquetas) de los videos que la aplicación crea y publica.

La aplicación también guarda en el disco duro de la computadora del usuario un archivo local con los tokens de acceso y actualización que Google emite al autorizar, junto con la configuración del proyecto (por ejemplo, la privacidad por defecto de las subidas). Este archivo no sale de esa computadora.

4. Cómo se procesa y comparte la información

Las operaciones sobre YouTube (subir, programar, cambiar privacidad, consultar estado) se envían directamente a la API de YouTube con la autorización del usuario y solo afectan al propio canal del usuario. Los datos no se comparten con terceros internos ni externos: ni se venden, ni se alquilan, ni se transfieren a otros servicios. La aplicación no muestra anuncios de terceros y no coloca cookies ni tecnologías de seguimiento.

5. Reducción del alcance y transparencia

La aplicación solicita los permisos (alcances) mínimos necesarios para su función e indica siempre el estado de privacidad elegido antes de cada subida. El usuario conserva el control total: ninguna acción se ejecuta sin su consentimiento explícito.

6. Retención y eliminación de datos

Los tokens guardados localmente se conservan únicamente mientras el usuario usa la aplicación. Para eliminar esos datos alcanza con borrar de la computadora la carpeta de configuración de la aplicación (archivo youtube_tokens.json) o revocar el acceso.

Además de cualquier procedimiento de borrado de la aplicación, el usuario puede revocar el acceso de Construyendo Valores Studio a sus datos de Google/YouTube en cualquier momento desde la página de seguridad de Google: https://security.google.com/settings/security/permissions. Al revocar el acceso, la aplicación deja de poder actuar sobre el canal.

7. Protección de datos de niños

La aplicación no recopila, almacena ni procesa información personal de niños ni de ninguna persona que vea los videos. Los videos producidos se marcan como "hechos para niños" (Made for Kids, valor selfDeclaredMadeForKids: true) conforme a la política de la plataforma.

8. Uso limitado de los datos de usuario de Google

El uso que Construyendo Valores Studio hace de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado (Limited Use).

  • Los datos de YouTube se usan solo para subir, programar y consultar el estado de los videos del propio canal autorizado.
  • No se usan para publicidad, perfilado, scoring, préstamo, venta ni para entrenar modelos de inteligencia artificial.
  • No se transfieren a terceros, salvo cuando es necesario para prestar la función solicitada por el usuario o para cumplir la ley.
  • Ninguna persona lee los datos, salvo el propio dueño del canal.
