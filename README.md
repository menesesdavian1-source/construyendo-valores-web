# Construyendo Valores Studio — sitio oficial

Documentos públicos de la aplicación **Construyendo Valores Studio**, una herramienta de
escritorio de un solo usuario para producir y publicar videos infantiles educativos en el canal
de YouTube [Construyendo Valores](https://www.youtube.com/channel/UCMD3CbCEBS0qH_-5_JlD9IQ).

Contacto: menesesdavian1@gmail.com

Este sitio existe para cumplir los requisitos de revisión de la YouTube Data API v3 y del
proceso de verificación de la pantalla de consentimiento de OAuth de Google.
